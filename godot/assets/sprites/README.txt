СЮДА КЛАДИ СВОИ PNG-КАТИНКИ, ЧТОБЫ ЗАМЕНИТЬ ГРАФИКУ ИГРЫ.

Имена файлов (строго такие, маленькими буквами):

  knight.png     — рыцарь (рекомендуемый размер 10x12 px).
                   Если нарисован БЕЛЫМ цветом — игра сама
                   окрасит его в цвет каждого игрока.
                   Можно и цветным — тогда modulate лишь слегка
                   тонирует (для мёртвых затемняется).
  king.png       — король (например 16x18), рисуется по центру трона
  heart.png      — сердечко жизни (3x3 или больше)
  sword.png      — меч (например 24x5), вращается вокруг ЦЕНТРА картинки
  floor.png      — тайл пола арены (любой кратный размер, замощается)
  bg_arena.png   — фон арены целиком (320x212) — перекрывает floor/сетку/стены
  torch.png      — факел (например 9x12)
  pillar.png     — колонна зала короля
  throne.png     — трон (например 25x26)

Порядок действий:
  1. Нарисуй картинку (Aseprite / GIMP / Paint.NET / даже Paint).
  2. Сохрани как PNG с прозрачным фоном.
  3. Положи файл в эту папку (assets/sprites/).
  4. Перезапусти Godot — он импортирует PNG автоматически.
  5. Запусти игру — она уже использует твою картинку.

Если какого-то файла нет — эта часть рисуется старой встроенной графикой.
Хочешь вернуть всё назад — удали PNG отсюда.

ВАЖНО для пиксель-арта: при импорте в Godot у PNG включи
 Filter = Nearest (выдели текстуру в FileSystem -> Import -> Preset:
 "Pixel" или снимите галку Filter), иначе картинка будет мыльной.
